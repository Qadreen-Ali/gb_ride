# GB Ride — API Specification

> GB Ride uses **Supabase** as its backend. There is no custom REST API server. All data operations go through the Supabase Flutter SDK which internally uses PostgREST (auto-generated REST) and Realtime (WebSocket streams).

## 1. API Design Guidelines

### Supabase SDK Pattern
All API calls are made through the `SupabaseClient` instance:
```dart
final _client = Supabase.instance.client;
```

### Operations Map
| Operation | Supabase SDK Method |
|-----------|-------------------|
| Create | `_client.from('table').insert(data).select()` |
| Read (one) | `_client.from('table').select().eq('col', val).maybeSingle()` |
| Read (many) | `_client.from('table').select().eq('col', val)` |
| Update | `_client.from('table').update(data).eq('id', id)` |
| Delete | Soft delete: `.update({'is_deleted': true})` |
| Real-time | `_client.from('table').stream(primaryKey: ['id'])` |

### Conventions
- All table/column names use `snake_case`
- IDs are UUIDs (auto-generated by Supabase)
- Timestamps are ISO 8601 strings
- Enums are stored as plain strings (e.g., `'requested'`, `'pending'`)
- `select()` after `insert()` to return the created row (with generated `id`)
- Error handling: try/catch with `throw Exception('...')` pattern

## 2. Authentication Approach

### Magic Link (Email OTP)
```dart
// Send magic link
await supabase.auth.signInWithOtp(
  email: 'user@example.com',
  emailRedirectTo: 'gbride://login-callback',
);

// Session is auto-restored by Supabase SDK
final user = supabase.auth.currentUser;
final authId = user?.id; // UUID string
```

### Auth State Listener
```dart
supabase.auth.onAuthStateChange.listen((data) {
  if (data.event == AuthChangeEvent.signedIn) {
    // Navigate to splash → role detection → home
  }
  if (data.event == AuthChangeEvent.signedOut) {
    // Navigate to login
  }
});
```

### Role Detection
After auth, the splash screen checks if the user exists in `drivers` or `locals` table:
```dart
// Check drivers table
final driver = await supabase.from('drivers').select().eq('auth_id', authId).maybeSingle();
// Check locals table
final local = await supabase.from('locals').select().eq('auth_id', authId).maybeSingle();
```

## 3. Endpoint List (Service Methods)

### RideService — Ride Operations

#### 3.1 `createRideRequest(RideModel ride)` → `String rideId`
**Table**: `rides`  
**Operation**: INSERT  
**Purpose**: Local creates a new ride request.

```dart
// Request
final rideId = await rideService.createRideRequest(RideModel(
  rideId: '',                     // auto-generated
  localId: 'uuid-of-local',
  pickupLocation: 'Jutial, Gilgit',
  destinationLocation: 'Airport Road',
  pickupLat: 35.9208,
  pickupLng: 74.3144,
  destLat: 35.9350,
  destLng: 74.3330,
  distanceKm: 3.5,
  etaMinutes: 10,
  fare: 200.0,
  createdAt: DateTime.now(),
));

// Response: returns the UUID of the created ride
// rideId = "a1b2c3d4-..."
```

#### 3.2 `findNearbyDrivers(lat, lng, radiusKm)` → `List<Map>`
**Table**: `drivers`  
**Operation**: SELECT + client-side Haversine filter  
**Purpose**: Find online drivers within radius (default 5km).

```dart
// Request
final drivers = await rideService.findNearbyDrivers(
  lat: 35.9208,
  lng: 74.3144,
  radiusKm: 5.0,
);

// Response: List of driver maps
// [
//   { "id": "uuid", "full_name": "Ali", "current_lat": 35.92, "current_lng": 74.31, ... },
//   ...
// ]
```

#### 3.3 `watchRideRequests()` → `Stream<List<Map>>`
**Table**: `rides`  
**Operation**: STREAM (real-time)  
**Filter**: `status = 'requested'`  
**Purpose**: Drivers watch for available ride requests.

```dart
// Usage
rideService.watchRideRequests().listen((requests) {
  // requests = List<Map<String, dynamic>>
  // Each map is a rides row with status='requested'
});
```

#### 3.4 `cancelRide(String rideId)` → `void`
**Tables**: `rides` + `ride_offers`  
**Operation**: UPDATE  
**Purpose**: Cancel a ride and expire all pending offers.

```dart
await rideService.cancelRide('ride-uuid');
// rides.status → 'cancelled'
// ride_offers.status → 'expired' (where ride_id matches and status='pending')
```

#### 3.5 `updateRideFare(String rideId, double newFare)` → `void`
**Table**: `rides`  
**Operation**: UPDATE  
**Purpose**: Local adjusts base fare while waiting (±5 PKR).

```dart
await rideService.updateRideFare('ride-uuid', 205.0);
```

#### 3.6 `updateRideStatus(String rideId, RideStatus status)` → `void`
**Table**: `rides`  
**Operation**: UPDATE  
**Purpose**: Driver updates ride through lifecycle stages.

```dart
await rideService.updateRideStatus('ride-uuid', RideStatus.onWay);
// Auto-sets completed_at when status is 'completed'
```

#### 3.7 `watchRide(String rideId)` → `Stream<RideModel?>`
**Table**: `rides`  
**Operation**: STREAM  
**Purpose**: Both local and driver watch real-time ride changes.

```dart
rideService.watchRide('ride-uuid').listen((ride) {
  // ride = RideModel? (null if deleted)
  // Fires on every change to this ride row
});
```

#### 3.8 `getRide(String rideId)` → `RideModel?`
**Table**: `rides`  
**Operation**: SELECT (one-time)  
**Purpose**: Fetch a single ride by ID.

```dart
final ride = await rideService.getRide('ride-uuid');
```

### RideService — Offer Operations

#### 3.9 `sendOffer(RideOfferModel offer)` → `String offerId`
**Table**: `ride_offers`  
**Operation**: INSERT  
**Purpose**: Driver sends a fare bid on a ride request.

```dart
final offerId = await rideService.sendOffer(RideOfferModel(
  offerId: '',                    // auto-generated
  rideId: 'ride-uuid',
  driverId: 'driver-table-uuid', // NOT auth_id
  driverName: 'Ali Khan',
  driverPhone: '+923001234567',
  driverImage: 'https://...',
  driverRating: 4.5,
  driverTotalRides: 120,
  offeredFare: 250.0,
  etaMinutes: 5,
  createdAt: DateTime.now(),
));

// Response: returns the UUID of the created offer
// offerId = "e5f6g7h8-..."
```

#### 3.10 `watchOffers(String rideId)` → `Stream<List<RideOfferModel>>`
**Table**: `ride_offers`  
**Operation**: STREAM  
**Filter**: `ride_id = X` AND client-side filter `status = 'pending'`  
**Purpose**: Local watches incoming driver offers in real-time.

```dart
rideService.watchOffers('ride-uuid').listen((offers) {
  // offers = List<RideOfferModel> (only pending ones)
});
```

#### 3.11 `acceptOffer(...)` → `void`
**Tables**: `rides` + `ride_offers`  
**Operation**: Multiple UPDATEs  
**Purpose**: Local accepts one driver's offer. Assigns driver, sets fare, expires others.

```dart
await rideService.acceptOffer(
  offerId: 'offer-uuid',
  rideId: 'ride-uuid',
  driverId: 'driver-table-uuid',
  driverName: 'Ali Khan',
  driverPhone: '+923001234567',
  driverImage: 'https://...',
  acceptedFare: 250.0,
);

// Result:
// 1. rides row: driver_id set, status='accepted', fare=250, accepted_at set
// 2. Accepted offer: status='accepted'
// 3. All other pending offers: status='expired'
```

#### 3.12 `hasDriverOffered(rideId, driverId)` → `bool`
**Table**: `ride_offers`  
**Operation**: SELECT  
**Purpose**: Check if driver already bid on this ride (prevent duplicates).

```dart
final alreadyBid = await rideService.hasDriverOffered(
  rideId: 'ride-uuid',
  driverId: 'driver-table-uuid',
);
// true if a pending offer exists
```

#### 3.13 `watchMyOffer(String offerId)` → `Stream<RideOfferModel?>`
**Table**: `ride_offers`  
**Operation**: STREAM  
**Purpose**: Driver watches if their offer was accepted or expired.

```dart
rideService.watchMyOffer('offer-uuid').listen((offer) {
  if (offer?.status == 'accepted') { /* rider chose me! */ }
  if (offer?.status == 'expired') { /* rider chose someone else */ }
});
```

### LocationService — GPS Operations

#### 3.14 `startLocationBroadcast(userId, userType)` → `void`
**Table**: `drivers` or `locals`  
**Operation**: UPDATE (every 10 seconds)  
**Purpose**: Broadcast GPS coordinates to Supabase.

```dart
locationService.startLocationBroadcast(
  userId: 'auth-uuid',
  userType: 'driver', // or 'local'
);
// Updates current_lat, current_lng, updated_at every 10s
```

#### 3.15 `stopLocationBroadcast()` → `void`
**Purpose**: Stop GPS timer.

#### 3.16 `getDriverLocation(driverId)` → `Map<String, double>?`
**Table**: `drivers`  
**Operation**: SELECT  
**Purpose**: Fetch a driver's last known coordinates.

```dart
final loc = await locationService.getDriverLocation('driver-uuid');
// { 'lat': 35.92, 'lng': 74.31 }
```

---

### AuthController — Auth Operations

#### 3.17 `signInWithEmail(String email)` → `void`
**Service**: Supabase Auth (GoTrue)  
**Purpose**: Send magic link to email.

#### 3.18 `signOut()` → `void`
**Service**: Supabase Auth  
**Purpose**: Clear session.

#### 3.19 `deleteAccount()` → `void`
**Tables**: `drivers` or `locals`  
**Operation**: UPDATE (`is_deleted = true`) + sign out  
**Purpose**: Soft delete user account.

## 4. Example Request/Response Patterns

### Creating a Ride (Full Round-Trip)
```dart
// 1. Build the model
final ride = RideModel(
  rideId: '',
  localId: localDbId,
  pickupLocation: 'Jutial Bazar',
  destinationLocation: 'NLI Colony',
  pickupLat: 35.9208,
  pickupLng: 74.3144,
  destLat: 35.9180,
  destLng: 74.3050,
  distanceKm: 2.1,
  etaMinutes: 7,
  fare: 150.0,
  createdAt: DateTime.now(),
);

// 2. Insert (toMap() excludes 'id')
final response = await _client.from('rides').insert(ride.toMap()).select();

// 3. Supabase response
// [
//   {
//     "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
//     "local_id": "...",
//     "driver_id": null,
//     "pickup_location": "Jutial Bazar",
//     "destination_location": "NLI Colony",
//     "pickup_lat": 35.9208,
//     "pickup_lng": 74.3144,
//     "dest_lat": 35.918,
//     "dest_lng": 74.305,
//     "distance_km": 2.1,
//     "eta_minutes": 7,
//     "fare": 150.0,
//     "status": "requested",
//     "driver_name": null,
//     "driver_image": null,
//     "driver_phone": null,
//     "created_at": "2026-03-05T12:00:00.000Z",
//     "accepted_at": null,
//     "completed_at": null
//   }
// ]

// 4. Extract the auto-generated ID
final rideId = response[0]['id']; // "a1b2c3d4-..."
```

### Real-Time Stream Event
```dart
// Supabase stream emits full table state matching the filter
_client.from('rides').stream(primaryKey: ['id']).eq('status', 'requested')
// Emits: List<Map<String, dynamic>> — all rows where status='requested'
// Re-emits whenever any matching row is inserted, updated, or deleted
```

## 5. Error Handling Standards

### Service Layer
All service methods follow this pattern:
```dart
Future<ReturnType> someMethod() async {
  try {
    // Supabase operation
    final response = await _client.from('table')...;
    
    if (response.isEmpty) throw Exception('Descriptive message');
    return result;
  } catch (e) {
    throw Exception('Method name error: $e');
  }
}
```

### Controller Layer
Controllers catch service exceptions and show user-facing snackbars:
```dart
try {
  await rideService.someMethod();
  Get.snackbar('Success', 'Action completed');
} catch (e) {
  Get.snackbar('Error', e.toString());
}
```

### Error Categories
| Category | Handling |
|----------|---------|
| Network errors | Caught by try/catch, shown as snackbar |
| Auth errors | Supabase SDK handles token refresh; expired sessions redirect to login |
| Empty responses | Checked with `.isEmpty`, throws descriptive exception |
| Stream errors | Streams auto-reconnect (Supabase SDK behavior) |
| GPS errors | Caught in LocationService, logged to console |
| Duplicate offer | Checked proactively with `hasDriverOffered()` before insert |

### Error Message Format
- Service layer: `throw Exception('Operation name error: $e')`
- Controller layer: `Get.snackbar('Error Title', e.toString())`
- Never expose raw database errors to users in production
